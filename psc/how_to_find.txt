HOW TO FIND SPECIFIC OS PROGRAMS IN psc/
==========================================

1. BROWSE BY TOPIC FOLDER
-------------------------
  exact_solutions/                       -> EXACT easiest solutions for all 34 questions in os questions.docx
  01_synchronization_and_shared_memory/  -> race conditions, bounded buffer, mutex, semaphores, monitors
  02_multithreading/                     -> pthreads, stats, matrix, fibonacci, bank, parallel sum
  03_cpu_scheduling/                     -> FCFS, SJF, SRTF, RR, Priority, MLQ, MLFQ, HRRN
  04_pipes_and_ipc/                      -> pipe(), mkfifo(), shm_open(), signals (kill/SIGUSR1)
  05_process_management_fork/            -> fork(), wait(), exit status, orphan, zombie, execvp()
  06_file_handling_and_commands/         -> open/read/write/lseek/stat, cd, ls, mkdir, grep, cat, cp, sort

2. SEARCH FROM TERMINAL
-----------------------
  Find by filename:
    find psc -name "*pipe*"

  Find by keyword inside code:
    grep -rn "mkfifo" psc/

3. COMPILE AND RUN ANY FILE
---------------------------
  clang -pthread path/to/file.c -o out && ./out
